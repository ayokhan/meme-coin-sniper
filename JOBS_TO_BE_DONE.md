# NovaStaris — Jobs to Be Done (JTBD)

**Product:** NovaStaris (novastaris.ai)  
**Last updated:** 2025

This document describes the **jobs** users hire NovaStaris to do—expressed as: **When** [situation], **I want to** [motivation], **so that** [outcome].

---

## 1. Discovery & evaluation

| # | When … | I want to … | So that … |
|---|--------|-------------|-----------|
| 1.1 | I’m looking for new meme coin opportunities on Solana or BSC | See new pairs and trending tokens in one place (new pairs, final stretch, migrated, trending) | I can find potential entries early without checking multiple tools. |
| 1.2 | I want to focus on tokens with momentum | See surge / volume-spike tokens | I can prioritize tokens that are already moving. |
| 1.3 | I’m not sure if a token is worth attention | Get an AI viral score and a clear buy/no-buy signal with reasons | I can decide faster and with more confidence. |
| 1.4 | I’m interested in BSC meme coins | Use BSC tabs (new pairs, trending) and, as Pro/VIP, run BSC AI Analysis | I have the same discovery and AI edge on BSC as on Solana. |
| 1.5 | I care about narratives or themes | See tokens grouped by narratives (if configured) | I can trade around themes I believe in. |
| 1.6 | I want to see what’s being talked about on CT | See token mentions from Crypto Twitter (CT Scan) and trigger a scan | I can align with hype and community buzz. |

## 2. Wallet tracking & alerts

| # | When … | I want to … | So that … |
|---|--------|-------------|-----------|
| 2.1 | I follow specific “smart money” or influencer wallets | Get alerted when multiple tracked wallets buy the same token | I don’t miss coordinated or high-conviction buys. |
| 2.2 | I want to know when a tracked wallet buys a token for the first time | Get first-buy alerts (when enabled) | I can react to genuine first entries. |
| 2.3 | I can’t watch the dashboard all day | Receive Wallet Tracker alerts in Telegram | I stay informed without staying on the site. |
| 2.4 | I want to see recent activity from tracked wallets | See live trades from those wallets | I can confirm moves and timing. |

| # | When … | I want to … | So that … |

| 3.2 | Token data or sentiment may have changed | Trigger a refresh of AI analysis on pinned tokens | I have up-to-date scores and recommendations. |

## 4. Crypto futures

| # | When … | I want to … | So that … |

## 5. Account & security

| # | When … | I want to … | So that … |
|---|--------|-------------|-----------|
| 5.1 | I’m new and want to use pins or subscribe | Create an account (email/password or Solana wallet) | I can sign in and use authenticated features. |
| 5.2 | I forgot my password | Request a reset link by email and set a new password | I can get back into my account without losing it. |
| 5.3 | I want to keep my account safe or change my password | Change my password from my account page | I can rotate credentials when I want. |
| 5.4 | I want the app to match my preference | Switch theme (Light / Dark / System) | I’m comfortable in my preferred appearance. |
| 5.5 | I want to update my profile | Edit name, phone, country, and trading experience in Account | My info is correct and you can tailor support or segments later. |

## 7. Support & communication

| # | When … | I want to … | So that … |
|---|--------|-------------|-----------|
| 7.1 | I have a question or problem | Open a support ticket or use chat | I can get help and resolve issues. |
| 7.2 | I prefer to talk to a human | See “Live: online” and request a live agent in chat | I get real-time help when available. |

## 8. Owner / operator jobs

| # | When … | I want to … | So that … |
|---|--------|-------------|-----------|
| 8.1 | I need to know if key integrations are healthy | Open the Status page and see DexScreener/Moralis health | I can fix issues before users are impacted. |
| 8.2 | I need to manage my business | See customers, subscriptions, and delete users if needed | I can run billing and compliance. |
| 8.3 | I need to handle support | List and update support tickets and respond in live chat | I can resolve user issues and keep satisfaction high. |
| 8.4 | I need to tune Wallet Tracker | Add/remove tracked wallets and set alert rules (min buyers, age, max alerts) | Alerts stay relevant and not noisy. |
| 8.5 | I need to control features during testing or incidents | Toggle feature flags (e.g. Moralis, Telegram) | I can disable parts of the system without a full deploy. |
| 8.6 | I want to understand my audience | View App Insights (country, city, device, path, browser, OS) | I can prioritize regions and improve UX. |
| 8.7 | I want to improve the AI model | Submit feedback (good/bad + note) on AI analyses | The product gets better over time from real outcomes. |
| 8.8 | I want to run or tune the trading bot | Configure provider, symbol, strategy, and trigger a run | I can automate or test strategies in one place. |
