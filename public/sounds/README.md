# Welcome sound

Place a coin-pouring sound effect here to play after the welcome voice:

- **`coins-pour.mp3`** – plays right after “Welcome to NovaStaris! Let’s print Money.”

If this file is missing, the app uses a short procedural coin-clink sound instead.

You can use any royalty-free coin/money sound (e.g. from [Mixkit](https://mixkit.co/free-sound-effects/coin/) or [Pixabay](https://pixabay.com/sound-effects/search/coins%20falling/)).
